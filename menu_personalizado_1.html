5. Menú Personalizado 1

Configura el comportamiento del enfoque automático, selección AF, velocidad AF y prioridad del disparo en AF-S o AF-C.

5.1 Botón AF/MF

Cambia entre AF y MF mientras se mantiene pulsado el botón AF/MF:
• Control AF/MF → El botón se utiliza para cambiar entre enfoque automático y enfoque manual.
• Bloqueo AF → El botón se utiliza como botón de bloqueo AF. Mantén pulsado AF/MF para fijar el enfoque y dispara con el botón principal.

Referencia: [Pág. 111 – Cambio sencillo de AF/MF]

Ver detalle: [Pág. 57 – Cambio sencillo de AF/MF]

5.2 Control AF/MF

Si [Botón AF/MF] está ajustado en [Control AF/MF], se puede cambiar el modo de operación del botón:
• Retener → AF y MF se conmutan sólo mientras se mantiene pulsado el botón.
• Alternar → Pulsa y suelta el botón para cambiar entre AF y MF.

Referencia: [Pág. 111 – Control AF/MF]

5.3 Velocidad AF

Selecciona la velocidad de enfoque cuando se activa el AF:
• Rápido → Confirma el enfoque con mayor rapidez (útil en acción).
• Lento → Confirma el enfoque más despacio, puede ayudar a evitar cambios bruscos.

Referencia: [Pág. 111 – Velocidad AF]

5.4 Visual.área AF

Controla cómo se ilumina el área AF local seleccionada en el visor:
• 0,6 s → El área AF local se ilumina en rojo durante 0,6 segundos.
• 0,3 s → El área AF local se ilumina durante 0,3 segundos.
• Desactivar → El área AF local se ilumina sólo cuando se pulsa el multiselector.

Referencia: [Pág. 111 – Visual.área AF]

5.5 Botón ret.enfoq

Si utilizas un objetivo equipado con botón de retención de enfoque, puedes cambiar su función para previsualizar la toma:
• Ret.enfoque → El botón mantiene el enfoque bloqueado mientras se pulsa.
• Previsual.Ópti → El botón se usa para previsualización óptica (cierra el diafragma a la apertura seleccionada).
• Previs.Intel. → El botón activa la previsualización inteligente (simula exposición, balance de blancos, etc.).

Referencia: [Pág. 112 – Botón ret.enfoq]

5.6 Rev.automática

Después de grabar una imagen, la cámara puede mostrarla automáticamente en el monitor LCD durante un tiempo determinado:
• 10 s, 5 s, 2 s → Muestra la imagen durante el tiempo seleccionado.
• Desactivar → No se muestra la imagen automáticamente.

Nota: en la revisión automática no se visualizará la imagen en posición vertical aunque se haya tomado en vertical.

Referencia: [Pág. 112 – Rev.automática]

Ver detalle: [Pág. 120 – Rev.automática]

5.7 Func.Previsual.

Selecciona qué tipo de previsualización se utiliza al pulsar el botón de previsualización:
• Inteligente → Usa la previsualización inteligente (simula exposición, balance de blancos, estilos creativos, etc.).
• Previsual.Ópti → Usa sólo previsualización óptica (diafragma real sin simulación electrónica adicional).

Referencia: [Pág. 112 – Func.Previsual.]

Ver detalle: [Pág. 84 – Utilización de la función de previsualización]
